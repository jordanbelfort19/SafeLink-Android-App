# SafeLink – Android Safety Application

SafeLink is an Android-based personal safety application designed to provide users with quick access to emergency assistance and nearby help services.

## 🚀 Features

* 🆘 Emergency/SOS assistance
* 📍 Location-based services
* 🗺️ Google Maps integration
* 🏥 Find nearby help and emergency locations
* 🔥 Firebase integration
* 📡 Bluetooth service integration
* 📱 Simple and user-friendly Android interface

## 🛠️ Tech Stack

* **Language:** Java
* **IDE:** Android Studio
* **Backend/Database:** Firebase
* **Maps:** Google Maps API
* **Build System:** Gradle
* **Platform:** Android

## ⚙️ Setup

1. Clone the repository:

```bash
git clone https://github.com/jordanbelfort19/SafeLink-Android-App.git
```

2. Open the project in **Android Studio**.

3. Add your Firebase configuration file:

```text
app/google-services.json
```

4. Add your Google Maps API key in the appropriate Android configuration.

5. Sync the project with Gradle.

6. Build and run the application on an Android device or emulator.

## 🔐 Configuration

For security reasons, Firebase configuration files and API keys are not included in this repository.

You need to provide your own:

* `google-services.json`
* Google Maps API key
